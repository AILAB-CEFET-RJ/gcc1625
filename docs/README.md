# Página do curso — GCC1625

Esta pasta contém o site estático da disciplina **GCC1625 — Inferência Estatística**.

## Arquivos

- `index.html`: conteúdo da página.
- `styles.css`: estilos visuais e responsivos.

## Publicação com GitHub Pages

1. No repositório, abra **Settings**.
2. Acesse **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main`.
5. Selecione a pasta `/docs`.
6. Salve.

A página deverá ser publicada em:

```text
https://ailab-cefet-rj.github.io/gcc1625/
```

## Atualização

Edite `index.html` para alterar conteúdo ou cronograma e `styles.css` para
alterar a apresentação visual. Depois, faça commit e push normalmente.
